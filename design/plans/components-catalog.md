2026-11-17 修订：根据用户反馈，搜索移至共享 Header，焦点采用内收的中性灰线。图片预览使用同一 DOM 的静止和活动状态；shader 封面改为真实 renderer 初帧。暂停、移出后保留已初始化画面并停止计算，重新激活续播；仅键盘焦点优先于鼠标移入。以下最初规划中“独立搜索栏”和“回到静态首帧”以本修订为准。

明确点击 Pause 或按 Escape 后会保持暂停，重新聚焦、移入不自动恢复；再次激活 Preview 才续播。

## 1. 目标与依据

- 目标路由：`/components`；当前实现位置：`apps/web/app/components/page.tsx`。
- 模式：Operate。开发者与 UI 设计师通过搜索、分类和效果预览找到适合项目的组件，再进入详情页。
- 视觉依据：当前目录实现、`DESIGN.md` 与本文件中已确认的页面方案。沿用现有首页的品牌、字体体系与蓝色强调色。
- 当前只展示四个真实演示；未实现的组件、框架支持和详情功能不作为现有能力展示。
- 英语界面、桌面布局；保留现有 1200px 最小文档宽度，不制作手机导航或手机排版。

## 2. 已确认范围

首版仅收录以下四个真实演示，静态首帧起步，鼠标移入或键盘聚焦时只激活当前卡片。

| 组件           | 分类       | 拟用英文说明                                   | 详情路径约定                 |
| -------------- | ---------- | ---------------------------------------------- | ---------------------------- |
| Metallic Text  | Text       | Metallic reflections that follow your pointer. | `/components/metallic-text`  |
| Hover Gallery  | Image      | Expand images as you explore the gallery.      | `/components/hover-gallery`  |
| Spatial Tunnel | Background | A rotating tunnel for immersive backgrounds.   | `/components/spatial-tunnel` |
| Image Focus    | Image      | Zoom into an image to explore the details.     | `/components/image-focus`    |

本轮规划列表页及其导航去向。详情、参数面板、复制源码、安装文档另行规划，不扩展首页视觉，也不补做未经确认的组件。

## 3. 页面结构

1. **共享页头。** 品牌返回首页，Components 为当前栏目；Examples 与 How to use 返回首页对应位置。沿用 GitHub 官方标志与 soon 状态。目录页不再重复同目标的 Browse components 按钮。
2. **紧凑介绍。** 标题 `Components`，说明 `Explore effects for text, images, and backgrounds.`，让搜索与首排效果尽早进入视线。
3. **搜索栏。** 输入提示 `Search components…`，按英文名称、描述及用途关键词过滤；⌘K / Ctrl+K 聚焦同一个输入框，不另做搜索弹窗。
4. **分类与数量。** `All`、`Text`、`Image`、`Background`；保持单选，与搜索共同生效。初始真实数量为 4，筛选后更新结果数。暂不展示没有条目的 UI 分类。
5. **预览网格。** 保留已确认的三列桌面结构，顺序如上表；四项自然排成 3 + 1，不加入占位卡补满。预览是主体，下方只放名称、一句用途和预览控制；详情入口仅在对应页面真实可用后加入。每张预览尺寸稳定，筛选后不因结果变少而拉伸卡片。
6. **列表收尾。** 显示 `Showing all 4 components` 或相应结果数量。四项不做分页、无限滚动或大型营销页脚。

首版暂不提供框架筛选和最近更新排序：当前没有多框架版本或更新记录。卡片不展示未经验证的 Vue 支持；未来框架元数据以可用源码为准。

## 4. 预览与导航行为

- 默认显示来自真实效果的静态首帧，卡片进入视口不自动播放；只有当前移入或聚焦的卡片运行预览。同一时间最多一个活动预览，键盘焦点优先于停留的鼠标。Gallery / Image Focus 使用同一套图片 DOM 呈现静态与动态，图片就绪后才开始动画；两种 shader 的首帧取自实际目录 renderer，首次激活才初始化 WebGL。
- 鼠标离开且卡片内没有焦点后，停止动态工作；暂停、离屏或页面转入后台也停止。已就绪的 renderer 保留当前画面和资源，恢复时继续播放，避免重新加载、重建上下文或切回不同构图的图片；卡片尺寸保持不变。
- 列表展示轻量效果，不复制详情页参数工具。Metallic Text 保留真实材质；Gallery 展示展开；Tunnel 展示旋转；Image Focus 展示局部放大，不嵌套完整家居网站页面。
- 预览区域与详情链接分开，避免把整张卡片链接包住可交互内容。Tab 聚焦明确的详情链接时激活对应预览，Enter 执行导航；不让用户为了查看列表逐个遍历演示内部控件。
- 尊重 reduced motion：默认静态，不因 hover 或 focus 强制播放；名称、说明与导航始终可用。
- 搜索与分类写入 URL，例如 `/components?q=text&category=text`。清除搜索和清除分类分别操作；返回列表恢复查询、分类与滚动位置。
- 详情路径仅为约定。进入详情的链接须在对应页面真实可用后启用；列表若先单独交付，保留可用预览和普通标题，不链接到 404 或伪造详情页面。

## 5. 必要状态

| 状态                        | 页面反馈                                                               |
| --------------------------- | ---------------------------------------------------------------------- |
| 初次进入                    | 展示四个真实首帧、All 分类及实际数量                                   |
| 搜索或分类命中              | 网格与数量同步更新，保留输入焦点；辅助技术可获知结果数                 |
| 搜索无结果                  | `No components found`，显示当前关键词并提供 `Clear search`             |
| 搜索与分类组合无结果        | 提供 `Clear category`，保留搜索词；必要时可分别清除条件                |
| 动态预览加载中              | 保持首帧与卡片尺寸，局部提示，不阻塞整页                               |
| 预览加载失败 / WebGL 不可用 | 保留静态效果及说明；加载失败可 `Retry preview`，不跳空白或影响其他卡片 |
| 键盘操作                    | 可见焦点、清晰选中态，预览不截获搜索框输入或导航按键                   |
| 内容增长                    | 新增真实条目后网格自然增长；分页、排序、多框架筛选随实际内容量另行引入 |

## 6. 实现边界与验收

- 建立一份组件元数据，统一名称、slug、分类、说明、搜索词、首帧与预览入口，避免首页与目录各写一套内容。
- 现有四个演示按首页尺寸实现，需抽出目录预览版本；复用原始效果逻辑和素材，保持首页当前外观与行为。
- WebGL 预览延迟初始化；不在列表首次加载时同时生成所有渲染器、文字遮罩或动画循环。动画继续使用 GSAP，界面图标继续使用 Lucide。
- 列表落地后，首页的 Components / Browse components 等目录入口改为 `/components`；现有 Examples / How to use 内容继续使用首页锚点。单项演示到详情的链接随详情上线接入。
- 验收桌面 1200、1440、1920 宽度下的结构、英文换行、卡片边界与首屏可见内容；窄窗口保留桌面结构，不引入手机布局。
- 验收真实数量、组合筛选、清除条件、键盘焦点、返回恢复、单卡播放、离屏停止、减少动效与预览失败回退。

后续开发顺序：页面骨架与真实数据 → 搜索和分类 → 四种轻量预览 → 导航与状态恢复 → 桌面视觉与性能检查。
