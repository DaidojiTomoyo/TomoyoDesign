# TomoyoDesign website

The English, desktop-only Next.js application for TomoyoDesign. Routes live in
`app/`; interactive demonstrations live in `components/effects/`.

Run these commands from the repository root:

```sh
pnpm install
pnpm dev:web
```

Open [http://localhost:3000](http://localhost:3000) for the homepage or
[http://localhost:3000/components](http://localhost:3000/components) for the
component catalogue.

See the [workspace README](../../README.md) for requirements, verification
commands, and project conventions, and the [asset index](../../design/README.md)
for image sources.
